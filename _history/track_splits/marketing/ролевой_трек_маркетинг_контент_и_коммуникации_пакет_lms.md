# Ролевой трек: маркетинг, контент и коммуникации. Пакет LMS

Дата: 22 марта 2026
Статус: единый источник истины для сборки модуля в LMS

## 1. Формат первого релиза

- `6` модулей;
- `6` коротких действий после уроков;
- `1` итоговый мини-проект;
- `6` основных материалов для скачивания;
- `1` управленческий scorecard для B2B-пилота.

## 2. Порядок модулей в LMS

| Раздел | Что получает участник |
|---|---|
| `M1` | канва маркетингового брифа |
| `M2` | карта сообщения и сегмента |
| `M3` | матрица переработки контента |
| `M4` | шаблон маркетингового черновика |
| `M5` | карта конкурентного и клиентского скана |
| `M6` | шаблон обзора маркетингового output |
| `RT-mkt-project` | один полный сценарий по своей живой задаче |

## 3. Нагрузка

| Тип нагрузки | Объем |
|---|---|
| видео | `1 ч 50 мин - 2 ч 15 мин` |
| чтение и шаблоны | `25-40` минут |
| практика | `90-150` минут |
| мини-проект | `60-90` минут |

## 4. Материалы для скачивания

1. `rt-mkt-brief-canvas`
2. `rt-mkt-message-map`
3. `rt-mkt-content-repurpose-matrix`
4. `rt-mkt-draft-structure`
5. `rt-mkt-competitor-client-scan`
6. `rt-mkt-weekly-output-review`
7. `rt-mkt-manager-scorecard`

## 5. Итоговый мини-проект

Участник должен сдать один цельный маркетинговый сценарий:
1. исходный запрос;
2. собранный бриф;
3. карта сообщения;
4. один черновик актива;
5. checklist проверки;
6. следующий шаг.
