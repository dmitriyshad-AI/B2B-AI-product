# Ролевой трек: клиентский сервис и сопровождение. Метрики и управленческий контур

Дата: 22 марта 2026
Статус: B2B-метрики и логика решения по пилоту

## 1. Что реально обещать

Можно обещать:
1. сокращение времени до первого ответа;
2. сокращение времени на сбор контекста;
3. повышение качества первого ответа;
4. ускорение эскалаций;
5. снижение cost-to-serve на типовых сценариях.

Нельзя обещать:
1. рост CSAT сам по себе;
2. автоматическое решение сложных обращений без человека;
3. автоматическую замену сервисной команды.

## 2. Базовые KPI пилота

1. время до первого ответа;
2. время на сбор контекста по обращению;
3. время на внутреннюю эскалацию;
4. доля обращений, где следующий шаг зафиксирован явно;
5. доля обращений, где использован единый шаблон;
6. weekly service review по команде.

## 3. Green / Yellow / Red

### Green
- первый ответ стал быстрее и стабильнее;
- команда использует единые шаблоны;
- эскалации стали короче и полезнее;
- owner видит один сценарий для закрепления.

### Yellow
- скорость выросла, но качество нестабильно;
- не по всем обращениям зафиксирован следующий шаг;
- шаблоны применяются не всей командой.

### Red
- команда не пользуется шаблонами;
- тексты по-прежнему пишутся с нуля;
- owner не видит безопасного сценария для масштабирования.
