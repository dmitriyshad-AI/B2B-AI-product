# Ролевой трек: клиентский сервис и сопровождение. Пакет LMS

Дата: 22 марта 2026
Статус: единый источник истины для сборки модуля в LMS

## 1. Формат

- `6` модулей;
- `6` практических действий;
- `1` итоговый мини-проект;
- `6` основных материалов для скачивания;
- `1` manager scorecard для сервисной функции.

## 2. Порядок модулей

| Раздел | Что получает участник |
|---|---|
| `C1` | карта triage и приоритета обращения |
| `C2` | шаблон выжимки контекста по тикету |
| `C3` | шаблон первого ответа |
| `C4` | шаблон эскалации |
| `C5` | шаблон сервисного follow-up |
| `C6` | таблица недельного обзора сервиса |
| `RT-cs-project` | один полный сервисный сценарий из своей практики |

## 3. Материалы для скачивания

1. `rt-cs-triage-card`
2. `rt-cs-ticket-summary`
3. `rt-cs-first-response-template`
4. `rt-cs-escalation-brief`
5. `rt-cs-followup-template`
6. `rt-cs-service-review-sheet`
7. `rt-cs-manager-scorecard`

## 4. Итоговый мини-проект

Участник должен сдать:
1. входящее обращение;
2. triage;
3. выжимку контекста;
4. первый ответ;
5. при необходимости эскалацию или follow-up;
6. вывод, что повторять как стандарт.
