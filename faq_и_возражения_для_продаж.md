# Sales FAQ And Objections

Дата: 21 марта 2026
Статус: максимально прикладной набор ответов на B2C и B2B возражения

## 1. Как пользоваться этим документом

Каждый ответ должен содержать четыре вещи:
1. короткий ответ без воды;
2. конкретику, что именно получает клиент;
3. proof point, который можно показать;
4. closing question, который двигает сделку дальше.

## 4. Когда не дожимаем продажу

### B2C stop cases

- человеку нужен курс по разработке, а не по прикладной работе;
- человек не готов выделять время на практику;
- человек ищет доходные обещания или "волшебный prompt pack".

### B2B stop cases

- нет owner со стороны клиента;
- нет безопасный для пилота функции или сценария;
- компания требует enterprise security contour до pilot phase;
- ЛПР хочет масштабировать без промежуточного пилота.

## 5. Тон ответа

Нельзя отвечать:
- хайпом;
- абстрактным "AI меняет мир";
- цифрами ROI без пилота;
- нападением на конкурентов.

Нужно отвечать:
- через конкретный сценарий;
- через конкретный deliverable;
- через конкретный следующий шаг в сделке.
