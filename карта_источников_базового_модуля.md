## 1. Зачем нужен этот файл

Этот файл нужен, чтобы по каждому элементу базовый модуль был один быстрый ответ на 6 вопросов:
- из какого сценария писать;
- из какого телесуфлер читать;
- из какого concrete-pack брать кейс;
- из какого visual-pack брать слайды и SVG;
- какой главный объект показывать в уроке;
- какой артефакт должен остаться у ученика после блока.

Этот файл не заменяет сами сценарии и пакеты.

Он заменяет поиск по десяткам документов вопросом:
`что именно использовать для этой единицы курса`.
