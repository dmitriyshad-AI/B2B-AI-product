# Pilot Facilitator Script

Дата: 21 марта 2026
Статус: operating script для запуска и сопровождения пилота

## 1. День 0. Старт

Что делаем:
1. отправляем доступ;
2. отправляем brief;
3. напоминаем про входную диагностику;
4. фиксируем дедлайн Session 0.

Короткий текст:

Стартуем пилот.

Первый шаг:
1. зайти в LMS;
2. пройти входную диагностику;
3. выполнить сравнение до / после;
4. пройти Session 0 в первые 48 часов.

Ваша цель сейчас не "посмотреть курс", а получить первый наблюдаемый рабочий результат.

## 2. День 3-4. Контроль ранней активации

Что проверяем:
1. кто прошел Session 0;
2. у кого есть первая практическая победа;
3. кто не стартовал;
4. есть ли системные вопросы по LMS-path.

Текст напоминания:

Если вы еще не прошли Session 0, сделайте это сегодня.

Это ключевая точка пилота: без первая практическая победа курс будет восприниматься как контент, а не как рабочий инструмент.

## 3. День 7-8. Midpoint

Что делаем:
1. смотрим completion;
2. собираем первые шаблоны;
3. проверяем, есть ли repeatable scenarios;
4. фиксируем точки трения.

Короткий вопрос участнику:

Какой один сценарий уже кажется рабочим?

Если ответа нет, значит нужно искать проблему не в мотивации, а в fit, LMS-path или content friction.

## 4. День 13-14. Финальный push

Что делаем:
1. напоминаем про HW5 и mini-project;
2. просим сохранить сильные артефакты;
3. готовим итоговый сбор цитат и артефакт результатаs.

Текст:

Финальная цель пилота:
1. сдать mini-project;
2. собрать 14-day plan;
3. сохранить один repeatable scenario и один рабочий шаблон.

Без этого пилот не даст сильного сигнала ни вам, ни нам.
