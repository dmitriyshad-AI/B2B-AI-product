# Стандарт продакшна базового модуля

Дата: 19 марта 2026
Статус: обязательный стандарт записи

## 1. Зачем нужен этот документ

базовый модуль будут записывать несколько людей.

Без единого production standard курс быстро развалится по:
- тону;
- глубине объяснения;
- темпу;
- качеству примеров;
- полезности для ученика.

Этот документ задает единый стандарт записи.

## 2. Обязательная структура каждого урока

Каждый урок строится так:
1. `Хук`:
   одна знакомая рабочая боль или ошибка.
2. `Обещание урока`:
   что конкретно ученик получит через 7-10 минут.
3. `Объяснение`:
   один принцип или одна рамка.
4. `Демонстрация`:
   один живой реалистичный пример.
5. `Вывод`:
   что важно запомнить.
6. `Действие`:
   что ученик делает сразу после урока.

## 3. Стандарт тона

Нужно говорить:
- уважительно;
- просто;
- без академической тяжести;
- без снобизма;
- без культа "секретных промптов";
- без техно-мистики.

Нельзя говорить:
- "AI все сделает за вас";
- "достаточно просто вставить этот промпт";
- "это заменит специалиста";
- "проверка не нужна".

## 4. Стандарт примеров

Примеры должны быть:
- рабочими;
- понятными взрослой аудитории;
- без излишне узкой отраслевой специфики;
- достаточно реалистичными, чтобы ученик узнал свою работу.

В каждом примере должно быть видно:
- исходная задача;
- запрос или логика работы с AI;
- слабое место;
- доработка;
- финальный полезный результат.

## 5. Стандарт глубины

В одном уроке:
- одна главная мысль;
- не больше одного главного фреймворка;
- не больше одного основного примера;
- не больше одного обязательного микро-действия.

## 6. Стандарт завершения урока

В конце урока преподаватель должен:
1. Повторить главную мысль одной фразой.
2. Сказать, что ученик делает сразу после урока.
3. Коротко связать урок со следующим шагом.

## 7. Стандарт для нескольких преподавателей

Если урок ведет не основной преподаватель:
- он все равно должен придерживаться общей структуры;
- терминология должна совпадать с базовый модуль;
- уровень сложности не должен резко отличаться;
- технические блоки не должны уходить в узкоспециализированную глубину.

## 8. Что считать неудачной записью

Неудачной считается запись, если:
- в ней много общих слов и мало пользы;
- преподаватель уходит в длинную теорию;
- нет понятного рабочего примера;
- нет шага, который ученик может сделать сразу;
- урок нельзя кратко пересказать одной практической мыслью.
