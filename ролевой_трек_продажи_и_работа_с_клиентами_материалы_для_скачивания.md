# Ролевой трек: продажи и работа с клиентами. Материалы для скачивания

Дата: 21 марта 2026
Статус: карта реальных материалов для скачивания по модулю

## 1. Как читать карту

Статусы:

1. `готово_html`
- есть реальный HTML-файл в репозитории;
- его можно сразу загружать в LMS или печатать в PDF.

2. `готово_как_источник`
- содержательная логика уже полностью описана в исходном документе;
- при необходимости файл можно собрать во второй формат без домысливания.

## 3. Правила качества

1. Первый экран каждого файла сразу показывает, что именно участник должен заполнить.
2. В каждом шаблоне есть не только поле для текста, но и рамка мышления.
3. Ни один файл не обещает "продажу вместо человека".
4. Во всех шаблонах зафиксирован следующий шаг, срок или решение.
5. Материалы пригодны и одному менеджеру, и команде как общий стандарт.
6. Дополнительные материалы должны помогать руководителю контролировать безопасность и эффект, а не просто украшать курс.
