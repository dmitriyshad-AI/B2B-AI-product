## 4. Что еще не сделано по первой волне

Остались не content-задачи, а production-задачи:
1. снять talking-head дубли;
2. снять или экспортировать screen capture;
3. собрать черновой монтаж;
4. проверить темп и ясность на реальном видео;
5. собрать тестовый LMS-контур для `сессии 0 + 1 + 5`.

## 5. Что не нужно делать

1. Не переписывать сценарии первой волны.
2. Не выбирать новые кейсы в день записи.
3. Не спорить между несколькими версиями файлов.
4. Не менять состав первой волны до черновой монтаж.

## 6. Переход к следующему шагу

Следующий правильный шаг:
1. записать первую волну;
2. сделать черновой монтаж;
3. проверить черновой монтаж через коллегию;
4. только после этого открывать массовую запись оставшегося Core.
