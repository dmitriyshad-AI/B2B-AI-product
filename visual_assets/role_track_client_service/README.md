## Что внутри

- `slides_outline.md` — покадровая структура по 6 модулям.
- `slide_copy.md` — готовый экранный текст для титульного экрана, главного рабочего экрана и финального экрана.
- `diagrams.md` — логика схем и компоновки.
- `18 SVG-экранов` — по 3 экрана на каждый модуль: титульный, главный рабочий и финальный.

## Логика продакшна

- Формат всех SVG: `1600 x 900`.
- Язык экранов: русский.
- В каждом модуле есть один главный экран:
  - `C1` — карта разбора и приоритизации обращения;
  - `C2` — выжимка контекста по тикету;
  - `C3` — структура первого ответа;
  - `C4` — бриф эскалации;
  - `C5` — структура контакта по зависшему вопросу;
  - `C6` — еженедельный обзор сервисных сигналов.
- Во всех модулях сохранен принцип: AI ускоряет разбор и черновики, но не заменяет ответственность владельца обращения.

1. Титульный экран открывает урок и фиксирует главную формулу.

3. Финальный экран закрывает урок, повторяет главный тезис и прикладное действие.
