# Покадровая структура визуальных материалов

## S1. Подготовка к диагностической встрече

1. Титульный экран — проблема хаотичной подготовки.
2. Главный экран — канва из 6 блоков: клиент, цель, гипотезы, вопросы, риск, следующий шаг.
3. Финальный экран — что заполнить сразу после урока.

## S2. Письмо по итогам встречи

1. Титульный экран — встреча бесполезна без фиксации следующего шага.
2. Главный экран — структура письма: обсудили, договорились, обещали, следующий шаг, срок.
3. Финальный экран — правило отправки письма в тот же день.

## S3. Ответы на возражения

1. Титульный экран — не отвечать одинаково на разные причины.
2. Главный экран — карта: возражение, причина, уточнение, ответ, следующий шаг.
3. Финальный экран — собрать 5 рабочих возражений своей команды.

## S4. Первый черновик КП

1. Титульный экран — не начинать предложение с пустого листа.
2. Главный экран — скелет КП: задача клиента, контекст, решение, объем, ограничения, следующий шаг.
3. Финальный экран — переписать одно реальное КП по новой структуре.

## S5. CRM-заметка

1. Титульный экран — CRM должна помогать продавать.
2. Главный экран — единый стандарт записи: стадия, контекст, сигнал клиента, риск, следующий шаг, дата.
3. Финальный экран — привести 3 сделки к одному стандарту записи.

## S6. Обзор воронки

1. Титульный экран — обзор воронки нужен для действия, а не для отчета.
2. Главный экран — таблица: что движется, что стоит, где риск, что делаем, где нужен разбор.
3. Финальный экран — собрать обзор 5-10 активных сделок на одной странице.
