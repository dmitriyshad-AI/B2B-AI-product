# Wave 2B Slides Outline

Дата: 21 марта 2026
Статус: outline реального visual deck для уроков 11-15

## Порядок использования

1. Сначала открыть нужный SVG-asset по уроку.
2. Затем свериться с `wave_2b_slide_copy.md` для точной формулировки в кадре.
3. Для process-логики и мостов между экранами использовать `wave_2b_diagrams.md`.
4. При необходимости пересобрать SVG через `build_wave_2b_assets.py`.
