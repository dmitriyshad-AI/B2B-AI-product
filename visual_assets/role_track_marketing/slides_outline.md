# Покадровая структура визуальных материалов

## M1. Маркетинговый бриф

1. Титульный экран — не брать в работу расплывчатый запрос.
2. Главный экран — канва брифа: цель, сегмент, сообщение, формат, доказательства, ограничения, следующий шаг.
3. Финальный экран — собрать один реальный бриф по новой структуре.

## M2. Карта сообщения

1. Титульный экран — разные сегменты нельзя кормить одной и той же формулировкой.
2. Главный экран — карта: кто, боль, ценность, доказательство, возражение, CTA.
3. Финальный экран — собрать message map для одной кампании.

## M3. Переработка одного исходника

1. Титульный экран — один сильный исходник должен работать в нескольких каналах.
2. Главный экран — матрица переработки: источник, главная мысль, канал, адаптация, проверка.
3. Финальный экран — превратить один исходник в три рабочих актива.

## M4. Первый маркетинговый черновик

1. Титульный экран — не начинать письмо, пост или секцию лендинга с пустого листа.
2. Главный экран — структура черновика: контекст, для кого, обещание, доказательство, ограничение, CTA.
3. Финальный экран — пересобрать один реальный материал по новой структуре.

## M5. Конкурентный и клиентский скан

1. Титульный экран — скан нужен для решения, а не для красивого файла.
2. Главный экран — карта скана: кого смотрим, что обещают, как доказывают, где окно для нас.
3. Финальный экран — собрать один короткий скан по конкуренту и сегменту.

## M6. Еженедельный обзор по выпуску материалов

1. Титульный экран — обзор нужен для решения, а не для ощущения занятости.
2. Главный экран — таблица: что выпущено, что в работе, что застряло, где bottleneck, что делаем на неделе.
3. Финальный экран — собрать weekly review по своей неделе.
