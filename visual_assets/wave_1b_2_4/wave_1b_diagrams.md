## Урок 4. Go / No-Go filter

```mermaid
flowchart LR
    A["Сценарий"] --> B{"Повторяется?"}
    B -->|Да| C{"Результат понятен?"}
    B -->|Нет| X["No-Go"]
    C -->|Да| D{"Риск умеренный?"}
    C -->|Нет| X
    D -->|Да| E{"Польза ощутима?"}
    D -->|Нет| X
    E -->|Да| F["Go"]
    E -->|Нет| X
```
