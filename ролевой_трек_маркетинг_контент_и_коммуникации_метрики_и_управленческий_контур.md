# Ролевой трек: маркетинг, контент и коммуникации. Метрики и управленческий контур

Дата: 22 марта 2026
Статус: B2B-метрики, baseline и решение по пилоту

## 1. Что реально обещать

Можно обещать:
1. сокращение времени от запроса к брифу;
2. сокращение времени от брифа к первому черновику;
3. рост throughput по маркетинговым активам;
4. снижение числа материалов, которые приходится пересобирать с нуля;
5. появление общей структуры и quality gate для команды.

Нельзя обещать:
1. рост выручки от маркетинга как автоматический результат;
2. рост ROMI без изменений в каналах и оффере;
3. автоматический рост лидов только из-за AI.

## 2. Базовые KPI пилота

1. среднее время на сборку брифа;
2. среднее время на первый черновик;
3. количество выпущенных активов на участника;
4. доля материалов, прошедших первый круг без полной пересборки;
5. наличие `1` общего шаблона и `1` общего quality checklist;
6. weekly output review без хаоса.

## 3. Green / Yellow / Red

### Green
- команда собирает единый бриф;
- время до первого черновика заметно сокращается;
- появился общий шаблон и общий checklist;
- owner понимает, что масштабировать.

### Yellow
- early value есть, но качество нестабильно;
- output растет, но quality gate еще слабый;
- часть команды работает по новой логике, часть нет.

### Red
- шаблоны не используются;
- материалы все еще пересобираются с нуля;
- owner не видит рабочего сценария для закрепления.

## 4. Решение по пилоту

В конце пилота руководитель должен ответить:
1. какой один сценарий становится командным стандартом;
2. где нужен manager review;
3. какие claims и обещания запрещены без ручной проверки;
4. стоит ли идти в следующую волну по маркетингу.
