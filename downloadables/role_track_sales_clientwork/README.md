# Материалы для скачивания: ролевой трек "Продажи и работа с клиентами"

Дата: 21 марта 2026
Статус: реальные HTML-шаблоны для LMS и печати

В этой папке лежат готовые HTML-материалы для скачивания по модулю.

Состав первого релиза:
1. `rt-sales-discovery-prep-canvas.html`
2. `rt-sales-followup-letter-template.html`
3. `rt-sales-objection-response-map.html`
4. `rt-sales-proposal-skeleton.html`
5. `rt-sales-crm-note-standard.html`
6. `rt-sales-pipeline-review-sheet.html`
7. `rt-sales-client-safe-use-rules.html`
8. `rt-sales-manager-scorecard.html`

Использование:
- загружать как HTML-материал в LMS;
- печатать в PDF из браузера;
- использовать как рабочий шаблон на экране или в распечатке.

Логика:
- первые 6 файлов работают как прикладные шаблоны для участников;
- `rt-sales-client-safe-use-rules.html` нужен как обязательный контур безопасной клиентской коммуникации;
- `rt-sales-manager-scorecard.html` нужен в корпоративной версии как управленческий слой измерения эффекта.
