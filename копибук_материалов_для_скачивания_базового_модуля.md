# Копибук материалов для скачивания базового модуля

Дата: 21 марта 2026
Статус: готовый к выгрузке copybook для handout-объектов базовый модуль

## 1. Как использовать этот файл

Этот файл нужен для материалов из `карта_материалов_для_скачивания_lms.md`, у которых статус:
- `copy_ready`
- или нужен чистый handout для PDF / DOCX / LMS text block

Формы `form_ready` остаются native LMS forms.
Материалы `linked_to_source` можно собирать напрямую из указанных source docs.

## 2. DL-L01. First Win Card

ID:
`dl-l01-first-win-card`

Заголовок:
`Карточка фиксации первая практическая победа`

Поля:
1. Рабочая задача
2. Baseline без AI
3. Что сделал AI
4. Что вы оставили после ручной доработки
5. Что стало лучше:
- быстрее старт
- лучше структура
- меньше хаоса
- проще следующий шаг
6. Что все еще требует проверки
7. Сохраню ли я этот сценарий? `да / нет / пока не знаю`

## 3. DL-L06. Prompt Formula Card

ID:
`dl-l06-prompt-formula-card`

Заголовок:
`Формула сильного запроса`

Каркас:
1. Цель:
что именно нужно получить
2. Контекст:
какая ситуация и какие вводные важны
3. Аудитория:
для кого предназначен результат
4. Формат выхода:
список, письмо, summary, таблица, memo
5. Критерии качества:
что обязательно должно быть в результате
6. Ограничения:
что нельзя, чего избегать, какой тон не подходит

Нижний блок:
`Слабый prompt -> Улучшенный prompt -> Что изменилось`

## 4. DL-L12. Quality Checklist

ID:
`dl-l12-quality-checklist`

Заголовок:
`Чек-лист проверки AI-ответа`

Чек-лист:
1. Факты:
нет ли выдуманных данных, подмены терминов или ложной точности
2. Логика:
нет ли скачков, противоречий и слишком гладких выводов
3. Полнота:
в ответе есть ключевые элементы задачи
4. Тон и адресат:
результат уместен для получателя
5. Применимость:
с этим можно идти в работу после ручной доработки
6. Риск:
нет ли красная зона последствий при blind copy-paste

Итоговое решение:
- использовать после правки
- переписать prompt
- отказаться от применения

## 5. DL-L15. Safe Use Rules

ID:
`dl-l15-safe-use-rules`

Заголовок:
`Минимальные safe-use правила`

Разделы:
1. Что можно:
- черновики писем
- summary обезличенных заметок
- структура и идеи
- prep к встречам
2. Что можно только после human review:
- клиентские формулировки
- внутренние summary по рабочим данным
- управленческие memo
3. Что нельзя:
- персональные данные
- договоры без проверки
- финансовые выводы без валидации
- конфиденциальные документы без policy

Нижний блок:
`Если сомневаешься, относись к задаче как к yellow-zone`

## 6. DL-L16. Follow-Up Template

ID:
`dl-l16-follow-up-template`

Заголовок:
`Шаблон follow-up после встречи`

Поля:
1. Контекст встречи
2. Что было решено
3. Следующий шаг
4. Кто owner
5. Какой срок
6. Какой нужен тон письма

Prompt scaffold:
`Помоги подготовить короткий follow-up после рабочей встречи...`

Checklist перед отправкой:
1. есть ли конкретный next step
2. указан ли owner
3. указан ли срок
4. нет ли лишнего "продажного" или неопределенного тона

## 7. DL-L17. Summary Template

ID:
`dl-l17-summary-template`

Заголовок:
`Шаблон summary документа или заметок`

Структура:
1. Короткая суть

## 11. DL-L21. Learning Guide

ID:
`dl-l21-learning-guide`

Заголовок:
`Как учиться с AI без самообмана`

Правила:
1. просите объяснить тему на вашем уровне, а не просто дать ответ
2. просите AI задавать встречные вопросы
3. проверяйте понимание через пересказ и применение
4. отделяйте learning support от проверки фактов
5. не подменяйте источники итоговым AI-summary
