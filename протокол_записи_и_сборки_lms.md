# Launch Protocol: Recording And LMS

Дата: 21 марта 2026
Статус: канонический launch protocol для production и LMS

## 1. Что делать первым

1. Открыть [3_пакет_перед_записью.md](/Users/dmitrijfabarisov/Projects/Dmitriy+Arseniy AI corp course/3_пакет_перед_записью.md).
2. Открыть [доска_записи_базового_модуля.csv](/Users/dmitrijfabarisov/Projects/Dmitriy+Arseniy AI corp course/доска_записи_базового_модуля.csv).
3. Подтвердить первый production sprint:
- сессия 0;
- урок 1;
- урок 5;
- урок 11;
- урок 16;
- урок 24.

## 2. Что делать после первой съемки

1. Сделать черновой монтаж этих 6 единиц.
2. Проверить:
- темп;
- звук;
- экранные демо;
- силу before/after;
- переходы между уроками.
3. Только после этого продолжать массовую запись.

### Stop rule

Если черновой монтаж не держит темп, первая практическая победа или ясность demo beat, массовую запись продолжать нельзя.

Сначала:
- закрываются точечные пересъемки;
- стабилизируется ранний блок;
- и только потом расширяется production wave.

## 3. Что делать параллельно в LMS

1. Открыть [пакет_сборки_lms.md](/Users/dmitrijfabarisov/Projects/Dmitriy+Arseniy AI corp course/пакет_сборки_lms.md).
2. Использовать [манифест_lms_базового_модуля.csv](/Users/dmitrijfabarisov/Projects/Dmitriy+Arseniy AI corp course/манифест_lms_базового_модуля.csv) как upload map.
3. Собрать тестовый контур в LMS только для:
- сессии 0;
- уроков 1-5;
- домашней 1.

## 4. Что считать успешным первым циклом

1. Понятно, что запись выглядит профессионально.
2. Понятно, что LMS-path не ломается.
3. Уроки 0-5 проходят без лишнего когнитивного шума.
4. Есть хотя бы один демонстрационный контур для first pilot.

Успешный первый цикл не означает, что внешний пилот уже можно открывать.

Он означает, что:
- production slice прошел видео-проверку;
- LMS-path не ломается;
- и можно собирать pilot-ready contour.

## 5. Что делать дальше

1. Доснять весь remaining Core по [доска_записи_базового_модуля.csv](/Users/dmitrijfabarisov/Projects/Dmitriy+Arseniy AI corp course/доска_записи_базового_модуля.csv).
2. Собрать полный Core в LMS.
3. Подготовить пакет артефактов результата для пилота:
- первая практическая победа;
- один шаблон;
- один чек-лист;
- один 14-day rollout artifact.

4. Принять отдельное решение:
- только внутренний QA продолжается;
- или можно открывать внешний pilot-ready контур.
